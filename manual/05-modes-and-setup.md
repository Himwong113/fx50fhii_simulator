## Ch-6

### 計算模式的選擇

本計算器共有六種「計算模式」。

#### 計算模式的選擇

1. 按 `MODE`。計算模式清單出現。計算模式清單有兩個畫面。按 `MODE` 進行選換。使用 `◀` 及 `▶` 也可選換清單畫面。

   畫面 1：`COMP  CMPLX  BASE`（1、2、3）；畫面 2：`SD  REG  PRGM`（4、5、6）。
2. 執行下述操作之一選擇所需要的計算模式。

| 要選擇此計算模式時 | 按此鍵 |
| --- | --- |
| COMP（運算） | `1`（COMP） |

## Ch-7

| 要選擇此計算模式時 | 按此鍵 |
| --- | --- |
| CMPLX（複數） | `2`（CMPLX） |
| BASE（基數） | `3`（BASE） |
| SD（單變量統計） | `4`（SD） |
| REG（雙變量統計） | `5`（REG） |
| PRGM（程式） | `6`（PRGM） |

按從 `1` 至 `6` 的數字鍵可選擇相應模式，無論目前顯示的清單畫面為何。

### 計算器設置

計算器設置可用於配置輸入及輸出設定、計算參數及其他設定。設置可使用設置畫面進行配置，按 `SHIFT` → `MODE`（SETUP）鍵可訪問設置畫面。共有六個設置畫面，用 `◀` 及 `▶` 可在其間進行選換。

#### 角度單位的指定

用於三角函數計算的角度單位可以指定為度、弧度或百分度。

90° = π/2 弧度 = 100 百分度。

| 角度單位 | 執行此鍵操作 |
| --- | --- |
| 度 | `SHIFT` → `MODE` → `1`（Deg） |
| 弧度 | `SHIFT` → `MODE` → `2`（Rad） |
| 百分度 | `SHIFT` → `MODE` → `3`（Gra） |

#### 顯示位數的指定

計算結果的顯示位數可在三種設定中選擇之一。固定的小數位數（0 至 9 位），固定的有效位數（1 至 10 位），或指數顯示範圍（兩種設定中選擇之一）。

| 指數顯示 | 執行此鍵操作 |
| --- | --- |
| 小數位數 | `SHIFT` → `MODE` → `▶` → `1`（Fix），然後 `0`（0）至 `9`（9） |
| 有效位數 | `SHIFT` → `MODE` → `▶` → `2`（Sci），然後 `1`（1）至 `9`（9），`0`（10） |
| 指數顯示範圍 | `SHIFT` → `MODE` → `▶` → `3`（Norm），然後 `1`（Norm1）或 `2`（Norm2） |

下面介紹計算結果是如何根據您指定的設定進行顯示的。

- 根據您指定的小數位數（Fix）顯示零到九位小數。計算結果被捨入到指定的小數位數上。

  範例：100 ÷ 7 = 14.286（Fix = 3）；14.29（Fix = 2）。
- 用 Sci 指定了有效位數後，計算結果使用有效位數及 10 位數的相應乘方進行顯示。計算結果被捨入到指定的位數上。

  範例：1 ÷ 7 = 1.4286 × 10⁻¹（Sci = 5）；1.429 × 10⁻¹（Sci = 4）。

## Ch-8

選擇 Norm1 或 Norm2 後，當計算結果在下示範圍之內時，其將以指數記數法顯示。

- Norm1：$10^{-2} > |x|$，$|x| \geq 10^{10}$。
- Norm2：$10^{-9} > |x|$，$|x| \geq 10^{10}$。

範例：100 ÷ 7 = 14.28571429（Norm1 或 Norm2）；1 ÷ 200 = 5. × 10⁻³（Norm1），0.005（Norm2）。

#### 分數顯示形式的指定

您可以指定假分數或帶分數形式顯示計算結果。

| 分數形式 | 執行此鍵操作 |
| --- | --- |
| 帶分數 | `SHIFT` → `MODE` → `▶` → `▶` → `1`（ab/c） |
| 假分數 | `SHIFT` → `MODE` → `▶` → `▶` → `2`（d/c） |

#### 複數顯示形式的指定

您可以指定直角座標形式或極座標形式顯示複數計算結果。

| 複數形式 | 執行此鍵操作 |
| --- | --- |
| 直角座標 | `SHIFT` → `MODE` → `▶` → `▶` → `▶` → `1`（a+bi） |
| 極座標 | `SHIFT` → `MODE` → `▶` → `▶` → `▶` → `2`（r∠θ） |

#### 統計頻率的設定

在 SD 模式或 REG 模式計算過程中，進行下述鍵操作可開啟或解除統計頻率。

| 頻率設定 | 執行此鍵操作 |
| --- | --- |
| 頻率開啟 | `SHIFT` → `MODE` → `◀` → `◀` → `1`（FreqOn） |
| 頻率解除 | `SHIFT` → `MODE` → `◀` → `◀` → `2`（FreqOff） |

### 計算模式及設置的清除

執行下述操作可清除目前的計算模式及所有設置，並將計算器初始化為下示配置。

| 項目 | 初始配置 |
| --- | --- |
| 計算模式 | COMP（運算模式） |
| 角度單位 | Deg（度） |
| 指數顯示 | Norm1 |
| 分數形式 | ab/c（帶分數） |
| 複數形式 | a+bi（直角座標） |
| 頻率設定 | FreqOn（頻率開啟） |

執行下述鍵操作可清除計算模式及設置。

`SHIFT` → `9`（CLR）→ `2`（Setup）→ `EXE`

不想清除計算器的設定時，請在上述操作中按 `AC` 而不按 `EXE`。
