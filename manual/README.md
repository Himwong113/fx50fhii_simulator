## 轉換說明

- 原始檔為本機提供的 `Casio fx-50FH II User Guide.pdf` 與同名資料夾內的 40 張雙頁 PNG 掃描；PDF 沒有可擷取的文字層。
- 保留原書繁體中文，不翻譯、不刪節成摘要。一般文字以 OCR 轉為可搜尋、可複製的 Markdown；已移除中文詞間的辨識空格並整理段落。主要章節標題、原書目錄、事前準備、安全須知、操作須知、在開始進行計算之前、計算模式及設置、電源要求及規格已對照掃描整理。
- **這是附原文影像的 OCR 轉換版本，並非逐字人工校訂本。** 部分繁體字仍可能辨識錯誤。遇到低信心文字、公式、分數、上下標、計算器按鍵、畫面及表格時，以原文影像保留，避免把不可靠的符號辨識結果當成正確文字。部分行內符號以高度 22 像素的原文圖片嵌入句子，保持敘述連貫。這些內容並非全部轉成可編輯的 LaTeX 或 Markdown 表格。
- 每個 `Ch-n` 小節最後的「完整原文影像」可展開校對；不支援 HTML 折疊的閱讀器也可直接開啟相對連結中的 PNG。分節影像僅含該部在該頁的範圍。同頁的兩部在各自檔案中接續，避免把後一部正文放入前一部。
- 原書目錄在 Ch-3–Ch-4，移至 `00-cover-and-contents.md`；其餘編號頁按原書順序保留。封面、封底與所有 MEMO／出版頁也已收錄。
- 原書網站、年份、科學常數及規格均依提供的版本保留。沒有以現行資料替換原書內容。
