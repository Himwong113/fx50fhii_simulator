# SD (Mode 4)

Enter `MODE → 4`. Type a value or expression and press **M+ (DT)** for each data line.
For frequencies, enter `value → SHIFT → , → frequency → M+` (FreqOn in SETUP).
AC clears the display and keeps data. M memory is independent of SD data entry.

| Keys after entering data | Command |
| --- | --- |
| SHIFT → 1 → 1/2/3 → EXE | Sum of squares / sum / count |
| SHIFT → 2 → 1 → EXE | Mean |
| SHIFT → 2 → 2/3 → EXE | Population / sample standard deviation |
| SHIFT → 2 → 2/3 → x² → EXE | Population / sample variance |
| SHIFT → 2 → ▶ → 1/2 → EXE | Minimum / maximum |
| SHIFT → 2 → ▶ → ▶ → 1/2 → EXE | Direct population / sample variance |

Use ▼/▲ to review x and frequency fields. Type a replacement and press EXE to
edit the selected field. SHIFT → M+ (CL) deletes its entire data line.
SHIFT → 9 → 1 → EXE clears all statistical data; AC cancels confirmation.
Changing calculation mode or frequency setting also clears data, per manual
Ch-35–38. FreqOn holds 40 lines; FreqOff holds 80 lines. Frequencies must be
positive safe integers. Sample deviation/variance requires at least two samples.

All state, math, parser tokens, screens, styles and tests live in this feature.
The existing MODE and SETUP owners delegate through namespaced actions.
